الطريقة الصحيحة للتشغيل، من مجلد المشروع:

npm run dev

ثم افتح http://localhost:3000

⚙️ الإعدادات

تُطبَّق الإعدادات فورًا دون إعادة تشغيل الخادم. مفتاح Gemini اختياري — بدونه تعمل الترجمة مجانًا عبر خدمات بديلة.

يُرسل مع طلب الحفظ كـ x-admin-token فقط عند تفعيله في الخادم (ADMIN_TOKEN). يُحفظ محليًا في متصفحك.
إذا كان مضبوطًا يظهر «مضبوط ✓» — تركه فارغًا يعني الإبقاء على المفتاح الحالي
يُستخدم ضمن الحد المجاني لخدمة MyMemory
يُرسل المزوّد المختار مع كل طلب ترجمة؛ «تلقائي» = سلسلة الاحتياط الحالية
مفتاح مجاني اختياري — يمنح جودة ترجمة أعلى، ويظهر «مضبوط ✓» عند وجوده
اختياري — للخدمات المتوافقة مثل OpenRouter/Groq
مثل Ollama أو LM Studio محليًا (بلا مفتاح)
أولوية المزوّدين عند الفشل — مفصولة بفواصل

📖 مسرد المصطلحات

كلمات تُستبدل دائمًا في النص المترجم — تُحفظ محليًا في متصفحك وتُرسل مع كل ترجمة.

🔍 قواعد الاستخراج (المواقع الصعبة)
