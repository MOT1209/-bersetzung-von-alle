# المتطلبات — Speed + Video Player + All Languages

## الأهداف

1. **السرعة:** التفريغ الصوتي أسرع 2-4x على الأقل (محرك STT أسرع + حذف خطوة wav الوسيطة).
2. **الفيديو المترجم:** الفيديو يشتغل داخل الصفحة والترجمة المترجمة تظهر متزامنة:
   - (أ) مشغل يوتيوب مضمّن + شريط ترجمة متزامن أسفله (افتراضي، فوري).
   - (ب) زر «تشغيل بترجمات مدمجة»: فيديو محلي + مسار WebVTT مرسوم فوق الفيديو.
3. **كل اللغات:** زر اختيار يضم ~130 لغة بأسماء عربية + بحث سريع.
4. **الكاش:** حفظ الترجمات في ملف JSON — نفس (نص، لغة) يُرجع فورًا بدون طلب شبكة، وشارة «⚡ من الذاكرة» في الواجهة عند الاستخدام.

## معايير القبول

- [ ] `npm run check` (node --check لكل ملفات server) سليم.
- [ ] الفيديو بدون ترجمات يُفرَّغ أسرع من الوضع الحالي (قياس زمني على نفس الجهاز).
- [ ] `POST /api/translate` يعيد `meta.cached: true` عندما تأتي كل الترجمة من الكاش.
- [ ] `GET /api/languages` يعيد قائمة ≥ 120 لغة `{code, nameAr}`.
- [ ] في الواجهة: بعد نتيجة يوتيوب يظهر الفيديو داخل الصفحة + شريط الترجمة المترجمة يتحدث مع تشغيل الفيديو.
- [ ] زر «تشغيل بترجمات مدمجة» ينزّل الفيديو ويعرضه بترجمات WebVTT فوقه.
- [ ] زر اللغة يعرض ≥ 120 لغة مع بحث.
- [ ] الواجهة RTL عربية — لا نص إنجليزي ظاهر.

## قيود

- لا مفاتيح API جديدة (STT محلي + gTTS + Google مجاني + Gemini موجود).
- بيئة Windows بطيئة + npm install بطيء جدًا → التثبيت في الخلفية مع مراقبة.
- لا قاعدة بيانات — الكاش ملفات JSON فقط.
- إبقاء المسار الحالي (whisper-tiny عبر @xenova/transformers) احتياطيًا إن فشل sherpa-onnx.
