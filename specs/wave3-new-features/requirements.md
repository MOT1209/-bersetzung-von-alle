# Requirements: Wave 3 — ميزات جديدة

## Summary

AraLink حاليًا يعمل بنموذج "الترجمة المتزامنة": يُرسل الطلب → ينتظر اكتمال الترجمة بالكامل → يعرض النتيجة دفعة واحدة. هذا يسبب تجربة سيئة للنصوص الطويلة (videos, articles) حيث قد يستغرق الانتظار 10-30 ثانية بدون أي تغذية راجعة.

الموجة3 تحل ثلاث مشاكل:
1. **بُطء الإدراك** — SSE يعرض الترجمة وهي تصل سطرًا بسطر
2. **غياب الرؤية** — لا توجد إحصائيات عن الاستخدام أو أداء المزوّدين
3. **ترجمة ذكية سطحية** — translate-smart يترجم النص بدون فهم سياقه أو نوعه

## Goals

### Feature 1: ترجمة بث مباشر (SSE)
- عرض كل سطر مترجم فور اكتماله (بدون انتظار باقي السطور)
- تقليل Time-to-first-token من ~5 ثوانٍ إلى <500ms
- الحفاظ على التوافق مع الوضع الحالي (fallback إلى JSON إذا لم يدعم المتصفح SSE)

### Feature 2: لوحة تحكم استخدامات
- رؤية شاملة: إجمالي الترجمات، التوزيع حسب النوع واللغة، أداء المزوّدين
- مخططات time-series (آخر7 أيام، آخر30 يوم)
- لا تتطلب تسجيل دخول — تعتمد على ADMIN_TOKEN فقط

### Feature 3: ترجمة ذكية مع سياق
- اكتشاف تلقائي لنوع المحتوى (مقال، كود، طب، قانون، عام)
- إضافة سياق الصفحة (العنوان، الوصف، نوع الموقع) إلى Gemmini prompt
- تحسين جودة الترجمة بنسبة ملحوظة للمحتوى المتخصص

## Non-Goals

- **ترجمة الفيديو المباشر (live streaming video)** — لا دعم للبث الحي، فقط النصوص
- **نظام مستخدمين/تسجيل دخول** — يبقى أداة مفتوحة بدون حسابات
- **ترجمة الصوت المباشر (real-time STT→translate→TTS)** — خارج النطاق
- **حضور تفاعلي (WebSocket)** — SSE كافٍ và أبسط
- **تصدير التقارير (PDF/Excel)** — يُضاف لاحقًا إذا لزم

## Acceptance Criteria

### SSE Streaming
- [ ] `POST /api/translate-stream` يُعيد `text/event-stream`
- [ ] كل سطر مترجم يُرسل كـ `event: chunk` مع `{index, text, total}`
- [ ] `event: init` يُرسل metadata قبل البدء
- [ ] `event: done` يُرسل عند الاكتمال
- [ ] ي渟عم fallback إلى JSON إذا فشل الاتصال
- [ ] Time-to-first-token < 2 ثانية

### Dashboard
- [ ] `GET /api/stats/timeseries?days=7` يُعيد بيانات يومية
- [ ] `GET /api/stats/providers` يُعيد إحصائيات المزوّدين
- [ ] صفحة `/admin.html` تعرض مخططات (bar chart, pie chart)
- [ ] المخططات تعمل بثيم dark/light
- [ ] تُخفي لوحة التحكم إذا لم يُضبط ADMIN_TOKEN

### Smart Context
- [ ] اكتشاف تلقائي لنوع المحتوى من URL + النص
- [ ] إضافة system prompt خاص بكل نوع محتوى
- [ ] `POST /api/translate-smart` يقبل `context` اختياري
- [ ] تحسين ملحوظ في جودة الترجمة للمحتوى المتخصص

## Assumptions

- Gemini API Key متوفر (مطلوب لـ translate-smart)
- المتصفح يدعم EventSource (جميع المتصفحات الحديثة)
- حجم البيانات الصغيرة (لا حاجة لـ WebSocket)
- لا يوجد قاعدة بيانات — يعتمد على ملفات JSON

## Technical Constraints

- **لا مكتبات خارجية للواجهة** — Chart.js عبر CDN فقط إذا لزم
- **RTL Arabic-first** — كل الواجهة عربي RTL
- **Stateless** — لا جلسات، لا قواعد بيانات
- **CF Workers / Vercel compatible** — SSE يجب أن يعمل على بيئة serverless
- **الحد الأقصى4500 حرف لكل طلب ترجمة** — chunking موجود مسبقًا
