٣ المكتبات المختارة — بنية «قوية المعلومات»

🎙️ أ — التفريغ الصوتي الأسرع (STT)

المكتبةالإصدارلماذا؟السرعة على CPU
sherpa-onnx (k2-fsa)
مُوصى به		 1.13.4 مكتبة «كالدى الجيل الجديد» من الفريق الذي صنع نماذج Whisper المدربة. حزم Node جاهزة لـ Windows x64 (تُنزّل تلقائيًا)، تدعم النماذج المتنقلة (streaming) والدفعات، وتبقى محلية 100% بدون إنترنت. أسرع من الوقت الفعلي ×1.5-4 مع whisper-tiny/base
whisper-node / nodejs-whisper
بديل		 1.1.1 / 0.3.1 روابط Node لـ whisper.cpp (محرك C++ فائق السرعة متعدد الخيوط). قد يحتاج بناء/تنزيل ثنائيات على Windows. سريع جدًا لكن إعداده أصعب
ترقية onnxruntime-node
بديل آمن		 1.14 ← 1.27 إبقاء نفس الكود لكن بمحرك ORT أحدث (تحسينات أداء + خيوط متعددة). أقل مخاطرة، مكسب متوسط. مكسب ~2-3x
✅ الخطة: نجرب sherpa-onnx أولًا (الأسرع)، وإن تعذّر تثبيته على هذا الجهاز نرتفع to onnxruntime-node 1.27 مع whisper-tiny. نُبقي الكود الحالي احتياطيًا.

🌍 ب — ترجمة «أي لغة» (قائمة ~130 لغة)

المحركاللغاتملاحظات
Google المجاني (الأساسي) ~130 لغة سريع ومجاني، لكن بحصة يومية/IP (429 مؤقتًا). نضيف قائمة كاملة بأسماء كل اللغات بالعربية في زر الاختيار + بحث.
Gemini API (احتياطي) ~100 لغة موجود — يُستخدم عند فشل Google.

🎬 ج — تشغيل الفيديو مع الترجمة المتزامنة

الخيارالتقنيةكيف يعمل
الخيار (أ): فيديو مضمّن + ترجمة تحته
مُوصى — سريع		 YouTube IFrame Player API + مؤقّت JS نشغّل الفيديو داخل الصفحة عبر مشغل يوتيوب الرسمي، ونعرض شريط الترجمة المترجمة أسفل الفيديو؛ نص يتحدث تلقائيًا مع currentTime (بدون تحميل الفيديو = فوري).
الخيار (ب): فيديو محلي + ترجمة فوقه
ترجمات حقيقية على الفيديو		 yt-dlp تنزيل + <video> + <track> WebVTT ننزّل الفيديو (خيار) ونشغّله بمشغل Plyr، والترجمة المترجمة تُرسم داخل الفيديو نفسه (ترجمة مصاحبة حقيقية مثل يوتيوب) لأن المتصفح يدعم مسارات WebVTT.
الخيار (ج): دبلجة صوتية TTS فوق الفيديو نستبدل الصوت بالقراءة العربية (gTTS) — أثقل وأبطأ؛ مرحلة لاحقة اختيارية.

٤ الواجهة الجديدة (بعد التطوير)

  1. شريط الإدخال: حقل الرابط + زر اختيار اللغة كبير واضح (قائمة منسدلة بـ 130 لغة + بحث سريع + «اكتشاف تلقائي» للغة المصدر).
  2. زر الترجمة: «ترجم الآن» — يبدأ الجلب والترجمة.
  3. منطقة النتيجة للفيديو:
    • 🎬 مشغل الفيديو في الأعلى (مضمّن يوتيوب — يعمل فورًا).
    • 💬 شريط الترجمة المترجمة أسفله مباشرة — جملة تلو الأخرى متزامنة مع اللحظة.
    • 📜 قائمة بكل الجمل (للتمرير/النسخ) + زر «تحميل SRT».
    • 🔊 زر «استمع بالعربية» (موجود).
    • ↩️ زر «العب فيديو محليًا بترجمات مدمجة» (خيار ب — تنزيل وتشغيل بترجمات WebVTT على الفيديو).
  4. منطقة النتيجة للمقالات: نفس العرض الحالي + زر القراءة الصوتية.

🎬 خيار (أ) — مضمّن يوتيوب

  • + فوري بدون تنزيل
  • + ترجمة متزامنة أسفل الفيديو
  • − الترجمة ليست «داخل» الفيديو

📺 خيار (ب) — فيديو محلي

  • + الترجمة تُرسم داخل الفيديو (مثل يوتيوب)
  • + تحكم كامل (إيقاف، سرعة، متابعة)
  • − يحتاج تنزيلًا (يستغرق وقتًا)

❓ قرارك المطلوب (1): أي شكل تشغيل تريد أولًا؟

❓ قرارك المطلوب (2): مستوى «أي لغة»؟

❓ قرارك المطلوب (3): هل نحفظ الترجمات السابقة؟

٥ مراحل التنفيذ (أمواج متوازية)

  • الموجة 1 — الأساس الخلفي للسرعة (ساعتان)
    • تبديل مسار التفريغ إلى sherpa-onnx (أو ترقية onnxruntime) مع إبقاء whisper-tiny احتياطيًا.
    • تحويل m4a → f32 مباشر بدون ملف wav وسيط.
    • إضافة كاش الترجمة الدائم (cache/translation-cache.json) على مستوى الجملة.
  • الموجة 2 — كل اللغات (ساعتان)
    • قائمة 130 لغة بأسمائها العربية + رموزها في زر الاختيار، مع حقل بحث.
    • عرض «اللغة المصدر المكتشفة» + مزامنة الرمز بين الواجهة والخادم.
    • ترجمة موازية خفيفة (2-3 دفعات) للنصوص الطويلة مع الحفاظ على الترتيب.
  • الموجة 3 — مشغل الفيديو المترجم (3 ساعات)
    • دمج YouTube IFrame Player API + شريط ترجمة متزامن أسفل الفيديو.
    • تحويل الشرائح إلى WebVTT (خادم) وتشغيلها عبر <video>+<track> في مشغل Plyr (خيار ب).
    • أزرار: استمع بالعربية، تحميل SRT، تشغيل محلي.
  • الموجة 4 — الصقل والاختبار (ساعتان)
    • قياس السرعة قبل/بعد، اختبار كل الأنواع (فيديو بترجمات/بدون، مقال، نص حر).
    • رسائل أخطاء عربية للحالات الجديدة، استجابة الجوال.
